This year I will hopefully be getting my hands dirty with ADA
code. These are some of my notes, which might be useful for
someone else trying to get an Ada environment up and running
for themselves on their private computer.

I have set this up to work on both WSL (Ubuntu) and my Mac.
Adjustments might be necessary, but refer to the dotfiles for
more info

P.S. I might update this document several times

## Getting the Ada Language Server (ALS) working with VIM and CoC

These are the bits that made me have a [pretty-much-functional LSP](https://forum.ada-lang.io/t/setting-up-the-ada-language-server-in-vim/1861/9) implementation working for ADA. It's not super smooth, 
seems a bit buggy (if you tail the log output at ~/.als/ada_ls_*), slow and sometimes gets
stuck at 100% CPU for extended periods of time, but it is useful :)

- My [CoC settings](https://github.com/fatso84/dotfiles/blob/afde07c02458c5048786fcba0a546b540e96b58d/common-setup/vim/dotvim/coc-settings.json#L21) for Ada
- [Download and install](https://github.com/fatso83/dotfiles/blob/add8a63e6b4f760b6971b9a2faa1ea6f4a473ecb/per-host-config/_shared/install-utils.inc#L143) Alire, GNAT, GPRBuild, GNAT Studio and ALS

Strictly speaking, GNAT Studio is not necessary, but nice to have for debugging.
Also, ALS is bundled with GNAT Studio, but it is a slightly older version.

My dotfiles also refer to specific versions, but by the time you read this, newer releases are bound to appear, so you might want to adjust the versions.

## Notes for macOS

No resources are being put into macOS from the AdaCore side, so it is all run by volunteers
like Simon J Wright. You get all you need, though, and Simon has FSF builds of the GNAT suite of tools
on his personal GitHub: https://github.com/simonjwright/distributing-gcc/releases

That will get you all the GCC stuff, GPRBuild, etc
